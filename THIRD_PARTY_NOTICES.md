# Сторонние компоненты

Версия, которую проверяют, не использует платные API, платные подписки и закрытые корпоративные лицензии. Интеграции с системами Альфа-Банка и государственными реестрами смоделированы локально. Живой интернет нужен только поиску товаров: SearXNG ходит в открытые поисковики, это не покупной датасет.

## Модель

| Модель | Откуда | Лицензия |
| --- | --- | --- |
| `qwen3.5:4b` | скачивает сервис `ollama-pull` из библиотеки Ollama | открытые веса Qwen, лицензия Tongyi Qianwen / Apache-2.0 |

Модель читает страницы товаров и выбирает предложения в пределах суммы кредита. Балл заявки она не считает. Более крупная `qwen3.5:9b` в проверку не входит: её можно подставить переменной `ML_LLM_MODEL`, но по умолчанию её нет.

## Данные

Синтетические SQL-моки в `src/registries/`. Это не выгрузки ЕГРЮЛ, ФНС, БКИ, Федресурса или арбитража. Компании, люди, договоры и суммы придуманы для демонстрации. Справочник категорий товаров — `src/registries/goods/01_goods.sql`. Задания поиска и найденные ссылки лежат в `ml.goods_searches`.

Поиск товаров при работающем интернете открывает публичные страницы магазинов, в том числе Яндекс Маркета. Ссылки и цены в подборке — ответ живого поиска на момент запроса, не зашитый каталог.

## Смоделированные интеграции

| Источник в кредитном процессе | Как воспроизведён |
| --- | --- |
| ЕГРЮЛ | схема `egrul` |
| ЕГРИП | схема `egrip` |
| ФНС, «Прозрачный бизнес» | схема `fns`: выручка, расходы, численность, задолженность |
| Реестр МСП | схема `msp` |
| Федресурс: банкротство и залог | схема `fedresurs` |
| Картотека арбитражных дел | схема `arbitration` |
| Бюро кредитных историй | схема `bki` и согласие по WebSocket `/bki-consent` |
| Подписание документов и выдача денег | не выполняются. В заявке хранятся названия документов, без содержимого и без электронной подписи |
| Счета клиента | отдельных счетов нет. Экран «Счета и платежи» показывает обороты выписки, которые клиент сохранил в заявке |
| Новостная лента | в этом кейсе её нет. Продукт — кредитный конвейер |

Ставка 16,9–19,9% на карточке решения — предварительная ставка продукта из калькулятора кабинета. Скоринг её не вычисляет.
