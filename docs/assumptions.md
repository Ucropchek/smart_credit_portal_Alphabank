# Допущения

Кейс разрешает упростить кредитное решение, подписание и выдачу, если смысл процесса сохраняется.

| Тема | Как сделано |
| --- | --- |
| Вход | Учётных записей нет. Режим «Предприниматель» и «Кредитный эксперт» переключается в интерфейсе. Для проверки это и есть тестовый доступ |
| Данные | Компании, люди и договоры синтетические, лежат в SQL-моках |
| Реестры | ЕГРЮЛ, ЕГРИП, ФНС, МСП, Федресурс, арбитраж и БКИ читаются из локального Postgres. Сеть до государственных сервисов не используется |
| Согласие на БКИ | Чекбокс уходит по WebSocket `/bki-consent` и привязывается к заявке. Без согласия договоры БКИ в балл не входят и стоп по просрочке не ставится |
| Скоринг | Балльная таблица портала в `BusinessScore.cs`, не коэффициенты Альфа-Банка. В ответе `model.alfaCoefficients` равен `false` |
| Решение | Балл — оценка риска. Итог сотрудника хранится отдельно. Одинаковый балл может дать разные суммы: потолок зависит от продукта и категории МСП |
| Порог | Нет стоп-факторов и балл не ниже 70 — `approve`. Ниже 70 — `review`. Ликвидация, текущая просрочка в БКИ или блокировка счёта — `reject` |
| Встречные условия | Если запрошенная сумма выше потолка, в заявке сохраняется меньшая сумма к выдаче и тот же срок |
| Ставка | 16,9–19,9% берётся из калькулятора по тексту цели, сумме и сроку. Балл ставку не считает. Для цели без «оборот», «оборуд» или «контракт» ставка на карточке не показывается |
| Выписка | Нет выписки или отказ — 0. Чистый поток не положительный — −8. Поступления меньше суммы кредита — +8. Поступления не меньше суммы — +16 |
| Документы | Хранятся имя и вид. Содержимое файла и электронная подпись не принимаются |
| Деньги | Выдача и платёж по кредиту не исполняются. Платёж на карточке — аннуитет по предварительной ставке |
| Товары | ML ищет публичные страницы. Пока сервис не готов, заявка и решение уже работают. Ошибка поиска не пишется клиенту по-английски |
| Новости | В кейсе одна фраза про новостную ленту. Остальной текст описывает кредитный конвейер, поэтому ленты в продукте нет |
