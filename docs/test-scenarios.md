# Тестовые сценарии

Запуск: `docker compose up --build`, кабинет http://localhost:3000. Учётных записей нет. Те же компании доступны по API, коллекция — [requests.http](requests.http).

| ООО «Первая контора» | `7701862572` | `1177700010014` | Банкротство, иск, просрочка в БКИ |
| ООО «Городская палата» | `5001033600` | ликвидирована, ОГРН в моке ЕГРЮЛ | Стоп-фактор ликвидации |

## 1. Кабинет поднимается

Открыть http://localhost:3000. Режим «Предприниматель». `GET http://localhost:8080/health` и `GET http://localhost:8000/health` отвечают `{"status":"ok"}`. Пока ML ждёт модель, кабинет уже открывается.

## 2. Заявка от потребности до результата

1. «Новая заявка». ИНН `7701990013` уже подставлен. «Найти» показывает карточку из реестров.
2. Цель «Покупка оборудования для компьютерной школы», сумма и срок. Выручка и численность подставлены из ФНС.
3. «Подставить примеры названий», согласие на БКИ, «Отправить в банк».
4. «Мои заявки» — у новой заявки шаг «Заявка подана», затем после действий банка шаги идут по порядку.
5. Режим «Кредитный эксперт»: «Обновить снимок», «Пересчитать». На карточке балл, расшифровка факторов и предварительная ставка, если цель содержит «оборуд», «оборот» или «контракт».
6. «Одобрить» и «Записать решение». В режиме предпринимателя та же заявка показывает решение банка.

Ожидание: данные не вводятся второй раз. Статус меняется `submitted` → `registryCheck` → `scoring` → `decision`.

## 3. Уточнение внутри продукта

В конвейере задать клиенту вопрос. В режиме предпринимателя ответить в заявке. Отдельной почты и мессенджера нет. Пока ответ не сохранён, сценарий «Запрос уточнения» открывает эту заявку.

## 4. Другие условия

Заявка с суммой выше потолка по баллу. После скоринга сумма к выдаче меньше запрошенной, срок тот же. Сценарий «Встречное предложение» открывает одобренную заявку, где сумма к выдаче меньше запроса. Если такой заявки нет, кабинет так и пишет.

## 5. Отказ по стопу

Найти ООО «Городская палата» или «Первая контора», подать заявку, снять реестры и пересчитать. Решение модели `reject`, в расшифровке виден сработавший стоп. Баллы факторов при этом всё равно посчитаны.

## 6. Выписка

Передать шесть месяцев оборотов. Строка «Выписка» в скоринге получает −8, +8 или +16 по правилу из [assumptions.md](assumptions.md), а не остаётся нулём при сохранённых оборотах.

## 7. Товары

У заявки с целью про оборудование блок «Товары под сумму кредита» переходит из ожидания в список ссылок либо в честный пустой статус. Английский текст ошибки клиенту не показывается.

## 8. ML без интернета и Ollama

Из `src/ml` после установки `requirements-test.lock`: `python -m pytest`. 35 тестов подменяют поиск, загрузку страниц и модель.
